## 🌟 About the Repository

Welcome! This repository serves as a personal coding portfolio and learning track for mastering the **C Programming Language**. It contains a variety of hands-on coding exercises, university/coursework practical exams, and modular projects designed to build strong foundational programming logic.

Whether you are looking to understand loops, memory management, or basic algorithm structures in C, you'll find organized code snippets and projects here!

## 📂 Repository Structure

The repository is organized into distinct directories based on topics and projects:

```text
📦 C-Language
 ┣ 📂 Loop               # Programs dedicated to mastering For, While, and Do-While loops
 ┣ 📂 Milan - Project    # A consolidated C language project incorporating multiple concepts
 ┣ 📂 Practical Exam     # Solutions and code files for structured practical examinations
```

### 🔍 Detailed Breakdown:

- 🔄 **Loop**: Contains fundamental to advanced logic building programs using iterative statements. Great for understanding control flow.

- 🛠️ **Milan - Project**: A dedicated folder for a larger, more complex project that ties together basic C principles into a functioning application.

- 📝 **Practical Exam**: Contains exact problem statements and their corresponding C code solutions asked in practical programming assessments.

## ⚙️ Getting Started

Want to compile and run these programs on your local machine? Follow these simple steps:

### 1. Clone the Repository

Open your terminal or command prompt and run:

```bash
git clone https://github.com/krish-desai-123/C-Language.git
cd C-Language
```

### 2. Install a C Compiler

Make sure you have a C compiler installed, such as GCC.

- **Windows**: Install MinGW or use WSL  
- **Mac**: Install Xcode Command Line Tools (`xcode-select --install`)  
- **Linux**: Run `sudo apt install build-essential`

### 3. Compile and Run Code

Navigate to the folder of the program you want to run. For example, to compile a file named `program.c`:

```bash
# Compile the C file
gcc program.c -o program

# Run the compiled executable
./program   # On Mac/Linux
program.exe # On Windows
```
